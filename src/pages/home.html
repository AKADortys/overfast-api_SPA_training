Introduction

This single-page application (SPA) is built on the Over-FastAPI (GitHub) to fetch and display data related to the Overwatch universe.

Key Technologies:

  • IndexedDB via Dexie: Local data storage to optimize performance and reduce API calls.
  • Bootstrap: Enhancing the user interface with a responsive and stylish design.
  • Fetch API: Interacting with Over-FastAPI's REST endpoints to dynamically retrieve information.

The project's goal is to efficiently leverage the data provided by Over-FastAPI and present it in a smooth and interactive interface without page reloads.

Application Architecture

This application is based on a modular structure where multiple classes interact to manage API requests, data storage, and dynamic DOM rendering.

📌 Main Structure

  • ApiOw: Performs HTTP requests to Over-FastAPI via Axios.
  • AppStorage: Uses ApiOw to retrieve and store data in IndexedDB.
  • AppDom: Manages component rendering and retrieves data from AppStorage.
  • App: Instantiates AppDom, handles navigation, and pagination.
